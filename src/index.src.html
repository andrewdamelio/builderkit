01 / fees

Fee calculator

Order fees use f in tenths of a basis point. f = 10 is 1 bp, or 0.01%. Caps: 0.1% on perps (f ≤ 100), 1% on spot (f ≤ 1000).

02 / approve

Approval maker

Users approve a max fee for your builder address once. The ApproveBuilderFee action must be signed by the user's main wallet, not an agent/API wallet. To revoke, approve "0%".

Parameters

The test key is generated in memory each session and never funded. Use it to test your submit pipeline end to end. Injected-wallet signing uses your wallet's active chain as signatureChainId.
